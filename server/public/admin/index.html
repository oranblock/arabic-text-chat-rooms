يسجل هذا القسم كافة الإجراءات الإدارية المتخذة (كتم، طرد، حظر جهاز، تغيير رتبة، قفل غرف، إذاعة عامة، حذف حسابات) مع هوية المسؤول وتوقيت التنفيذ والتفاصيل.

التوقيت المسؤول نوع الإجراء العضو المستهدف التفاصيل والسبب
