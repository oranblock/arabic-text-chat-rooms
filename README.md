## 📖 نبذة عن المشروع (Overview)
مشروع تطبيقي احترافي متكامل لنظام غرف الدردشة الجماعية والكتابية المخصصة للمجتمعات العربية، مبني بأحدث معايير جوجل لتطوير تطبيقات الأندرويد (**Modern Android Development - MAD**) باستخدام **Kotlin Jetpack Compose Material 3** وسيرفر محادثات فورية عالي الأداء مع نظام حماية وإشراف فائق الصرامة.

## ✨ المميزات الرئيسية والمطابقة الدقيقة للشروط الـ 9

تمت هندسة التطبيق خصيصاً لتلبية الشروط التسعة المحددة من العميل بكل دقة:

### 1. 🔵 الشريط العلوي الملكي (Royal Blue Top App Bar)
- شريط علوي أنيق بلون أزرق ملكي متناسق بارتفاع قياسي `56dp`.
- يحتوي على **5 أزرار تفاعلية سريعة**:
  1. 🔔 **مركز الإشعارات:** تنبيهات الإشارات والرسائل الجديدة.
  2. 🚪 **مبدّل الغرف (Room Switcher):** التنقل السلس بين الغرف العامة والخاصة.
  3. 👤 **الملف الشخصي (Profile):** تخصيص الصورة، اللقب، وألوان الاسم.
  4. ✉️ **البريد والخاص (Private Messages):** محادثات سرية مشفرة ثنائية.
  5. 👥 **طلبات الصداقة والغرف (Requests):** إدارة الإضافات والدعوات.

### 2. 💬 تصميم فقاعات الرسائل والأفاتار المنحني
- **أفاتار العضو:** مربع بزوايا منحنية أنيقة (`42dp × 42dp` مع CornerRadius `10dp`) مع إطار لوني يمثل رتبة العضو.
- **فقاعة الرسالة:** تصميم كارد ناعم ذو زوايا دائرية `12dp` مع خلفية نظيفة مريحة للعين.
- **التوقيت:** يظهر دائماً في **أقصى اليسار** بنظام 24 ساعة (`HH:mm`) بخط رمادي مصغر وواضح.
- **اسم العضو:** يظهر أعلى نص الرسالة مباشرة بلونه المخصص ورتبته.

### 3. 👑 نظام ألوان الرتب المخصصة (Role-Based Themes)
- 👑 **المالك / مدير الروم:** خط مميز باللون الذهبي الملكي الفاخر مع توهج داكن أنيق.
- 🛡️ **المشرف / الإدارة:** لون فضي/رمادي ملكي ثابت يعكس الهيبة والمسؤولية.
- 💎 **العضو الماسي (VIP):** علامة الماسة بجانب الاسم مع فتح صلاحية اختيار وتغيير لونه المفضل من شاشة حسابه.
- 👤 **العضو العادي:** لون كلاسيكي مريح مع إمكانية الترقية بناءً على نشاطه.

### 4. ⚡ ميزة النقر السريع للرد (Quick Mention On-Tap)
- بمجرد النقر على اسم أي عضو أو صورته الرمزية داخل ساحة الشات، يُنسخ اسمه فوراً في حقل الكتابة السفلي بصيغة `@اسم_العضو:`، مما يمنح تجربة تواصل سريعة وسلسة دون الحاجة لكتابة الأسماء يدوياً.

### 5. 👥 قائمة المتصلين الجانبية التفاعلية (Online Users Drawer)
- قائمة جانبية ذكية تنسحب بنقرة زر أو إيماءة سحب، تعرض المتواجدين حالياً في الغرفة مقسمين حسب رتبهم، مع إمكانية البحث السريع والتفاعل معهم.

### 6. 🎬 مشغل يوتيوب المدمج داخل الشات (In-Chat YouTube Floating Player)
- نافذة عائمة مصغرة مدمجة أعلى المحادثة لتشغيل المقاطع والبث المباشر ومشاركتها مع أعضاء الغرفة لحظياً، مع إمكانية تصغيرها أو تكبيرها أو كتمها دون مغادرة المحادثة.

### 7. 🛡️ نظام مكافحة التكرار والسبام والكتم التلقائي
- **الكتم التلقائي للأعضاء الجدد:** يدخل العضو الجديد الغرفة بحالة كتم مؤقتة لحين مصادقة المشرف لمنع الحسابات الوهمية والمزعجة.
- **مكافحة السبام (Anti-Flood Engine):** كشف الرسائل المتكررة وحظر الإرسال العشوائي بفواصل زمنية محددة.

### 8. 🔒 الحظر الصارم عبر معرّف الجهاز الفيزيائي (Hardware UUID Device Ban)
- نظام حظر متطور لا يعتمد على مجرد الـ IP أو البريد (حيث يسهل تجاوزهما عبر VPN أو فتح حساب جديد).
- يعتمد النظام على استخراج بصمة الجهاز الفيزيائية المشفرة (`Hardware Device UUID`) وحظر العتاد بالكامل، مما يمنع المخرب نهائياً من العودة حتى لو أعاد تثبيت التطبيق أو غيّر شبكة الاتصال.

### 9. 👻 وضع الشبح الذكي للمخربين (Ghost Mode)
- سلاح إداري خفي: عند تفعيل "وضع الشبح" على عضو مشاغب، يظهر له أن رسائله تُرسل بنجاح داخل الشات، لكن في الواقع **لا يراها أي شخص آخر في الغرفة سوا هو نفسه**!
- يضمن هذا الوضع تفريغ طاقة المخرب وإحباطه وتوقف إزعاجه دون علمه ودون أن يفتعل فوضى أو يحاول الدخول بحساب بديل فوراً.

## 🛠️ المعمارية التقنية وحزمة الأدوات (Tech Stack)

| الطبقة | التقنيات المستخدمة |
|---|---|
| **نظام التشغيل واللغة** | Android 8.0+ (API 26+) · Kotlin 2.0+ |
| **واجهات المستخدم (UI)** | Jetpack Compose · Material Design 3 · Dynamic Theming |
| **معمارية الكود** | Clean Architecture (Domain, Data, UI) · MVVM · MVI Events |
| **حقن الاعتماديات (DI)** | Koin 3.5+ (AndroidX Compose) |
| **الاتصال والبيانات** | Retrofit 2 · OkHttp 4 · Kotlinx Serialization · DataStore |
| **المحادثات الفورية** | Socket.io Client Android · WebSockets Realtime Engine |
| **السيرفر الخلفي (Backend)** | Node.js · Express · Socket.io · SQLite / PostgreSQL |
| **حماية العتاد والأمان** | Android KeyStore · Hardware UUID Hashing · Device Ban |
